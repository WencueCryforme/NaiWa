## 表情包

- 统一文件格式：`.png` `.gif`
- dist级：500KB以下的压缩版本，在目录 `dist/meme/` 下。
- raw级：生成/传播时的未压缩版本，在 [**表情包归档清单文档**](docs/meme-raw-list.md) 中有按批次release的列表，不直接包括在仓库内容中。

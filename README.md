## 表情包

- 统一文件格式: `.jpg` `.gif`
- dist 级: 500KB/2MB以下的压缩版本,存放于 `dist/meme/` 目录
- raw 级: 生成与传播时的未压缩版本,不直接包括在仓库内容中
- dist 级与 raw 级均随某个版本 Release 发布,归档列表见 [**表情包归档清单文档**](docs/meme-list.md)

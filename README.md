## 表情包

- 统一文件格式:`.png` `.gif`
- dist 级:500KB 以下的压缩版本,存放于 `dist/meme/` 目录
- raw 级:生成与传播时的未压缩版本,不直接包括在仓库内容中,按批次发布的归档列表见 [**表情包归档清单文档**](docs/meme-raw-list.md)
